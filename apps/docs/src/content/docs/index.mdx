## Guides

<CardGrid>
  <Card title="Getting started" icon="rocket">
    Create the admin account, build a form, publish it, share it, and read the responses.
    [Read the guide](/docs/guides/getting-started/)
  </Card>
  <Card title="Endpoint forms" icon="document">
    Keep your own HTML form. Post it to `/submit` and Probe stores it, emails it, and signs a webhook.
    [Read the guide](/docs/guides/endpoint-forms/)
  </Card>
  <Card title="AI form generation" icon="pencil">
    Describe a form in plain words and get a draft in the builder. Bring a key from any of eight providers.
    [Read the guide](/docs/guides/ai-generation/)
  </Card>
  <Card title="API and agents" icon="seti:json">
    Personal API keys, tRPC over HTTP, and `/llms.txt`, the contract agents read.
    [Read the guide](/docs/guides/api-and-agents/)
  </Card>
  <Card title="Deployment" icon="setting">
    Run Probe on Railway with a Postgres service, a custom domain and email. Troubleshooting included.
    [Read the guide](/docs/guides/deployment/)
  </Card>
  <Card title="Local development" icon="laptop">
    Postgres in Docker, schema push, demo data, and both apps on your machine.
    [Read the guide](/docs/guides/local-development/)
  </Card>
